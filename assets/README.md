# README visual assets

- `dashboard-v2.png`, `commit-draft.png`, `model-library.png`: rasterized **actual ANSI terminal output** from the current PushTrack CLI at 132 × 30 cells. Menlo, decorative terminal-window chrome and terminal faint-color presentation are supplied by a macOS AppKit renderer; they are not extra application features.
- All repositories and paths in these captures are temporary synthetic examples. The draft fixture changes `TIMEOUT = 10` to `TIMEOUT = 20`; its subject is supplied by a **fake transport**, not a real model. The model-library fixture is a placeholder file: its “present” label does not establish SHA-256 verification. The capture exercised modal opening/closing, preserved the synthetic index and restored the terminal.
- No private repository, real model inference, model download, training, or weight changes were used to make the UI captures. These images demonstrate interface layout, **not model quality, speed or successful large-context inference**.
- `feature-overview.png`: **AI-generated promotional illustration** based on the public synthetic UI captures and existing PushTrack icon. Its composed terminal panels are artwork, not unmodified screenshots or test evidence.
- `dashboard.png`: older sample-dashboard image, retained rather than overwritten.
- `pushtrack-icon.png`: existing PushTrack brand asset.

Real small-input inference observations and their limitations are documented separately in the [local-draft setup and evidence](../README.md#local-commit-message-drafts-experimental).
