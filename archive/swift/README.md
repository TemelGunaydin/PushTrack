# Archived Swift prototype

These sources are retained as a migration reference, including the unfinished Swift TUI work. They are not part of the active build and are no longer maintained or included in the current test results.

The supported implementation is the Rust application at the repository root. Its configuration remains compatible with the Swift prototype's `folders` JSON array at `~/.config/pushtrack/config.json` (or `$XDG_CONFIG_HOME/pushtrack/config.json`). No saved folders are deleted or rewritten by the migration.

See the root [README](../../README.md) for current installation, usage, and tests. `README.original.md` records the earlier documentation, not the current product behavior.
